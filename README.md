# OTO PLAZA - Auto Parts Store & Accessories (Elementor Pro Website Redesign)

A modern, high-converting, responsive e-commerce web application redesign for **OTO PLAZA** built with Elementor Pro design aesthetics.

## 🚀 Key Features

1. **Top Presentation Control Bar**:
   - Live interactive template switcher for 6 key pages (`Home`, `Shop Catalog`, `Product View`, `Vehicle Finder`, `Cart`, `Checkout`).
   - Responsive Viewport Switcher (`Desktop` vs `Mobile` 390px device simulation).

2. **OTO PLAZA Dramatic Hero Section**:
   - Racing orange & dark slate high-contrast theme matching the Elementor Pro redesign reference.
   - Interactive car silhouette showcase with floating fitment guarantee pills and quick action buttons.

3. **Interactive Vehicle Parts Finder ("Find Parts For Your Vehicle")**:
   - 4-level select controls (`Select Year`, `Select Make`, `Select Model`, `Select Engine / Trim`).
   - Dynamic fitment check alert displaying zero-risk fitment guarantee for selected vehicles.

4. **Promo Banners Grid (3 Feature Cards)**:
   - `Get your car fixed now` (Brakes & Suspension)
   - `Big Sale, Big Deal` (Engine Parts & Turbo Systems - Up to 40% Off)
   - `UX Interior Tuning` (Carbon Steering Wheels & Racing Seats)

5. **Flash SALE Section with Live Countdown Timer**:
   - Real-time ticking timer (`14h : 38m : 42s`).
   - Product cards with discount badges (`-25% OFF`), quick view eye trigger, wishlist heart, and instant cart additions.

6. **Interactive Shopping Cart Engine**:
   - Real-time quantity adjustment (`+` / `-`), item removal, live cart badge counter, and subtotal calculation.

7. **Express Checkout Wizard**:
   - Complete checkout interface with instant order placement confirmation modal.

## 📁 File Structure

- `index.html`: Complete semantic HTML5 markup containing all 6 templates and interactive components.
- `styles.css`: CSS3 design system with custom variables, glassmorphism elements, dark themes, and responsive media queries.
- `app.js`: JavaScript application logic for template switching, vehicle finder, shopping cart, and live countdown.

## 💻 Running Locally

Simply double-click `index.html` or serve with any local HTTP server:

```bash
npx serve .
```
